# 🏛️ Hometown Hub 

### 🌱 About the Project
**Hometown Hub** is a Digital Platform for Village Communication and Community Engagement. It serves as a digital village square where residents can stay connected, share updates, and interact with each other seamlessly.

### 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (Pure PHP)
* **Database:** MySQL

### 🚀 Key Features
* 👤 **User Authentication:** Secure Login and Registration system.
* 📝 **Create & Share Posts:** Users can write updates and upload images.
* ❤️ 💬 **Social Engagement:** Real-time Like and Comment system.
* 🔖 **Save Posts:** Feature to bookmark or save important updates for later.
* 🗑️ **Post Management:** Users can delete their own posts.
